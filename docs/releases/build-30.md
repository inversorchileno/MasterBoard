# Master Board V1.30

**Versiones para macOS y Linux**

- **macOS:** dos versiones, una para los Mac con chip Apple (M1, M2, M3, M4…) y otra para los Mac con procesador Intel. Se abre el `.dmg` y se arrastra Master Board a Aplicaciones.
- **Linux:** un AppImage que funciona en la mayoría de las distribuciones de 64 bits, sin instalar nada.
- En macOS y Linux, Acerca → Actualización abre la página de la nueva versión para descargarla; en Windows sigue instalándose sola.
- Primera versión para estos sistemas: se comprobó que compilan y abren, pero aún no se han probado a fondo.

---
**Descargas:** el `.zip` de Windows, el `.dmg` de macOS con chip Apple (M1, M2…) o con Intel, y el `.AppImage` de Linux.

**Aviso de seguridad:** la primera vez, Windows («Windows protegió su PC»: Más información → Ejecutar de todas formas) y macOS («no se puede verificar al desarrollador»: clic derecho → Abrir) muestran un aviso, porque Master Board no está firmado con un certificado de pago. Es un proyecto gratuito y de código abierto; el detalle está en la página principal del repositorio.
