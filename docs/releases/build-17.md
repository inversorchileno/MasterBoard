# Master Board, compilación 17

**Lector de PDF completo**

- Archivos recientes y reapertura de un PDF con sus notas.
- Imprimir (Ctrl+P), Extraer páginas (PDF, PNG o JPEG, por rangos) y Borrar página.
- Recuperación de documentos si el programa se cierra sin terminar.
- Búsqueda con lista de resultados; Índice del PDF y enlaces que funcionan.
- Vista continua de varias páginas; copiar texto del PDF con la flecha.
- Selección con lazo y Reconocer formas (un trazo a mano queda como figura limpia).
- Pantalla táctil: zoom y desplazamiento con dos dedos, palma ignorada.
- Las notas y los adjuntos quedan como comentarios y adjuntos dentro del PDF guardado.

---
Descarga el archivo `.zip` de Windows, descomprímelo y abre el programa, o actualiza desde **Acerca → Actualización**.
