# Master Board V1.27

**Versión 4 de las mejoras**

- Menú Herramientas: todas las herramientas de la pizarra y del escritorio.
- Menú Personalización: elige qué botones se ven en cada barra.
- Acerca → Atajos: todos los atajos de teclado, que se pueden cambiar, con aviso si chocan con Windows o con el programa.
- Panel de IA (ChatGPT, Claude, Gemini, Copilot, DeepSeek, Grok, Le Chat, Perplexity): resumen, traducción, crear imagen, quitar fondo, borrado generativo y transcribir audio.
- Las pestañas se reordenan arrastrándolas; la ventana de GIFs recuerda las cookies.

---
Descarga el archivo `.zip` de Windows, descomprímelo y abre el programa, o actualiza desde **Acerca → Actualización**.
