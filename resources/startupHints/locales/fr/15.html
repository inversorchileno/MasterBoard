Lecture à voix haute

Master Board lit le texte avec les voix de Windows.

  • Depuis le début : lit la page puis les suivantes.
  • Texte sélectionné : tracez un rectangle sur le texte à lire ; il est marqué en jaune.
  • Depuis le clic : lit à partir du mot touché.
  • Lire, Pause, Arrêter et Page suivante.
Aussi dans Édition → Lire et dicter → Lire à voix haute (Ctrl + Maj + L).
